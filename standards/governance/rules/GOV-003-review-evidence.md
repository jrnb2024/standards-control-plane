# GOV-003 — Review Evidence Must Be Traceable

**Domain:** governance  
**Version:** 1.0.0  
**Status:** active  
**Severity default:** medium

Work that claims review completion must leave traceable evidence of findings,
tests, or explicit deferrals rather than relying on unstructured narrative.

## Signals

- no evidence directory or review file for substantial work
- findings discussed in prose without IDs or status
- unresolved issues not marked as deferred, accepted, or resolved

## Rationale

The current estate already values review discipline. This rule makes the audit
surface consistent with that expectation.
