# GOV-002 — Required Planning Artefacts Must Exist

**Domain:** governance  
**Version:** 1.0.0  
**Status:** draft  
**Severity default:** high

Before non-trivial implementation work begins, the expected planning artefacts
must exist for the class of change being attempted.

## Signals

- missing requirement or strategy document for a new feature
- missing architecture document for backend-meaningful work
- missing design document for front-end workflow changes
- missing acceptance criteria

## Rationale

This rule operationalises the estate's existing documentation gate so that it
can be checked consistently rather than only by manual review.
