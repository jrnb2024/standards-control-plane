# Strategy — WP-SCP-018 Auth, Multi-Repo Reporting, and Richer Evidence Adapters

**Work Package:** `WP-SCP-018`  
**Version:** 0.1  
**Status:** Draft  
**Date:** 2026-04-12

## 1. Strategy

Extend the current system in three bounded directions:

- add optional bearer-token protection to the existing service surface
- aggregate existing Control Tower dashboards into a portfolio view
- add richer evidence buckets to extraction and normalisation contracts

This keeps the final slice additive and contract-driven rather than reopening
the core consult or audit flow.
